# 브랜드플래닝 자사몰 시안

압축을 풀고 `dist/index.html`을 열면 메인, 카테고리, 상품 상세, 매거진, 공지사항을 확인할 수 있습니다. 검색과 상품 필터, 가격순 정렬, 장바구니는 브라우저에서 동작합니다. 장바구니는 시안용이며 회원과 결제 시스템 연동은 별도입니다.

## GitHub Pages에 올리기

1. 압축을 푼 폴더의 내용을 GitHub 저장소의 `main` 브랜치에 추가합니다. `.github` 폴더도 함께 올립니다.
2. 저장소에서 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
3. **Actions → Deploy preview to GitHub Pages → Run workflow**를 실행합니다. 이후 `main`을 업데이트하면 워크플로가 다시 실행됩니다.
4. 배포가 끝나면 **Settings → Pages**에 표시된 `https://<계정>.github.io/<저장소>/` 형태의 주소를 공유합니다. 로컬 미리보기의 `http://localhost:8741/`는 작업 중인 컴퓨터에서 열립니다.

워크플로는 자바스크립트 문법과 이미지가 포함된 미리보기 빌드를 확인하고, `dist`를 배포합니다. `#catalog/weekly`와 `#product/13862254499` 같은 주소는 저장소 하위 경로에서도 직접 열 수 있습니다.

## 편집 및 데이터

- 화면 구조는 `dist/index.html`, 스타일은 `dist/styles.css`, 화면과 필터 동작은 `dist/app.js`에서 편집합니다.
- 상품 가격과 주문 가능 사이즈는 2026년 11월 25일에 스마트스토어에서 확인한 시안 데이터입니다. 상품과 마스킹된 구매 리뷰의 발췌 문구는 `dist/catalog.js`, 이미지 출처는 `media-sources.json`에 있습니다.
- 브랜드 메뉴(`#brands/all`)에서 알파벳순 목록을 확인할 수 있습니다. 개별 브랜드 상품에 성별과 상품군 필터를 적용할 수 있으며, 막스마라는 브랜드 결과 상단에 하위 라인을 표시합니다.
- 헤더의 지구본에서 한국어와 영어를 고를 수 있습니다. 선택은 브라우저에 저장되며, 매거진 본문과 구매 리뷰의 인용문은 한국어 원문으로 표시합니다. 800px 이하에서는 사용자·장바구니 아이콘을 표시하고, 사용자 아이콘으로 로그인 시안을 바로 엽니다. 520px 이하에서는 메뉴 아이콘으로 카테고리를 엽니다.
- 상품 상세는 스마트스토어에서 확인한 상품별 본문, 특징, 소재 구성과 원문에 별도로 표기된 소재 설명을 표시합니다. 한국어 원문과 영어 번역은 `PRODUCT_DETAILS`에 있습니다.
- 상품 카드에 마우스를 올리면 앞모습 착용 사진을, 착용 사진이 없는 경우 다른 각도의 사진을 보여줍니다. 상품 상세는 대표 사진으로 열리며 썸네일을 선택하면 큰 사진이 바뀝니다. 상품별 사진은 `PRODUCT_GALLERIES`에서 편집합니다.
- 장바구니(`#cart`)에서 개별 상품이나 전체 상품을 체크할 수 있습니다. 수량과 선택 상태가 저장되며, 선택 상품 합계가 표시됩니다. 선택 상품 구매와 전체 상품 구매는 각각 해당 상품만 주문서 미리보기로 넘깁니다. 상품 상세의 구매하기는 현재 사이즈와 수량으로 주문서를 엽니다. 실제 결제는 카페24 운영몰 연결 후 가능합니다.
- 브라우저 새로고침 시 현재 상품, 목록, 장바구니 페이지가 맨 위에서 다시 열립니다. 메인 주소를 공유하면 배너부터 열립니다. 기존 `#notice`와 `#review` 공유 링크는 각각 공지사항과 리뷰 목록을 엽니다.
- 메인, 위클리 카테고리, 위클리 상품 상세에 같은 초 단위 카운트다운을 표시합니다. 메인에서는 시간을 크게 강조합니다. 매주 월요일 15:00:00 한국 시간에 0이 되고, 15:00:01부터 다음 주 마감을 표시합니다.
- 메인 배너는 화면에 보일 때 5초마다 다음 배너로 넘어가고, 마지막 배너 다음에는 첫 배너가 같은 방향으로 이어집니다. 전환 중에 누른 버튼 입력은 쌓이지 않습니다. 리뷰는 화면에 들어오면 4초마다 한 장씩 넘어갑니다. 각각의 재생 버튼으로 멈추거나 다시 시작할 수 있습니다.
- 메인의 **리뷰 더보기**는 별도 구매 리뷰 목록(`#reviews/all`)을 엽니다. 목록과 메인의 리뷰 팝업에서 **해당 상품 보러가기**로 자사몰 상품 상세를 엽니다. 가격과 주문 옵션이 확인되지 않은 리뷰 상품은 상세에서 상품 문의로 연결합니다.
- 오른쪽 문의하기에서 **메일로 문의 보내기**를 선택하면 Formspree가 답변을 받을 이메일과 상품 문의 내용을 접수해 등록된 수신 주소로 전달합니다. **문의하기** 버튼은 카페24 운영몰에서 사용할 접수 완료 화면을 미리 보여줍니다. 전송 주소는 `dist/index.html`의 `data-inquiry-endpoint`에 설정되어 있습니다.
- 기획전(`#catalog/classic`)은 상품 데이터에 등록된 브루넬로 쿠치넬리와 톰 포드 상품을 모두 표시합니다. 메인 클래식의 캠페인 MP4는 화면에 들어오면 음소거로 반복 재생됩니다. 단일 HTML에도 영상이 포함됩니다.
- 매거진 카드는 자사몰 내부 글로 열립니다. 글 8편의 본문과 본문 사진은 `dist/catalog.js`의 `MAGAZINE_ARTICLES`에 있습니다. 기존 카페의 공통 배너와 카페 글 링크는 생략했습니다. 7개 표지는 본문 사진이며, 신발 글의 표지는 관련 상품 사진입니다.
- 커뮤니티(`#community/all`)는 예시 게시글을 보여주며 메인에는 처음 3개를 표시합니다. 입고 소식(`#arrivals/all`)은 회사 블로그의 Arrival Note와 New In을 각각 별도 목록으로 엽니다. 게시글과 원문 링크는 `dist/catalog.js`의 `COMMUNITY_POSTS`와 `ARRIVAL_POSTS`에서 편집합니다.
- 주 메뉴와 푸터의 공지사항은 `#notices/all`로 연결됩니다. 공지 목록과 상세 내용은 `dist/catalog.js`의 `NOTICES`에서 편집합니다.
- 이미지와 폰트를 포함한 단일 미리보기는 이 폴더에서 `node build-standalone.mjs dist preview.html`로 만들 수 있습니다.

## 카페24 기본 쇼핑몰에 적용하기

- 카페24 디자인 안에서 문의를 받을 때는 무료 기본 게시판의 글쓰기 모듈을 연결합니다. 문의 폼의 브랜드, 판매 페이지 URL, 사이즈, 기타 요청은 게시물 제목과 본문으로 저장하도록 구성합니다. 등록된 문의는 **관리자 → 게시판 → 게시물 관리**에서 확인합니다. 비회원 문의도 받으려면 일반 게시판의 쓰기 권한을 허용하고 **비밀 글 전체 잠금**을 사용합니다. [게시판 관리](https://support.cafe24.com/hc/ko/articles/7751500478233) · [쓰기 권한 설정](https://support.cafe24.com/hc/ko/articles/8462700436377)
- 새 글을 회사 메일로 받으려면 **내 쇼핑몰 정보 → 수신전용 이메일**에 주소를 등록하고 **메시지 → 알림 메시지 → 자동 알림 메일 관리 → 새 게시글 작성시 안내**에서 운영자 발송을 켭니다. 새 글 이메일 알림은 무료이며 게시판별 선택은 SMS에서 제공됩니다. [새 글 알림 설정](https://support.cafe24.com/hc/ko/articles/8465114011417)
- GitHub Pages처럼 분리된 화면에서 문의를 카페24에 바로 저장하려면 서버를 통해 카페24 게시판 등록 API를 호출하는 구성이 필요합니다. 운영자 API 인증 정보는 서버에서 관리합니다. [게시판 게시물 등록 API](https://apidocs.cafe24.com/docs/admin/post-boards-by-board-no-articles)
- 회원가입 할인 쿠폰은 **프로모션 → 쿠폰 관리 → 쿠폰 만들기**에서 금액 5,000원, 조건부 자동 발급, 회원가입으로 설정합니다. [회원가입 쿠폰 설정](https://support.cafe24.com/hc/ko/articles/8462501253145)
